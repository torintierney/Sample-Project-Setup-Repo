# Constraints and Dependencies

## Purpose
Document known constraints and dependencies early in discovery or delivery so they are visible to the full team. Constraints limit what the solution can do or how it must be built. Dependencies are external inputs or decisions the solution relies on. Both affect scope, sequencing, and risk.
