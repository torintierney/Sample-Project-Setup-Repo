# Definition of Done Template

## Item Details
- Item Type: [Epic | Story | Task]
- Item Name: [Enter name]
- Owner: [Name]
- Target Completion Date: [YYYY-MM-DD]

## Functional Completion
- [ ] All scoped requirements are implemented.
- [ ] Acceptance criteria are fully met.
- [ ] Edge cases and error handling are addressed.
- [ ] No known Sev1/Sev2 defects remain open for this item.

## Quality and Testing
- [ ] Unit tests added/updated and passing.
- [ ] Integration tests added/updated and passing.
- [ ] End-to-end/UAT validation completed.
- [ ] Test evidence is linked and reviewed.

## Security and Compliance
- [ ] Security controls and access requirements are implemented.
- [ ] Sensitive data handling follows policy.
- [ ] Compliance requirements are satisfied (if applicable).
- [ ] Audit/logging requirements are implemented (if applicable).

## Data and Observability (if applicable)
- [ ] Data quality checks are implemented and passing.
- [ ] Monitoring/alerts are configured and validated.
- [ ] Dashboards/metrics are updated.
- [ ] Operational runbook updates are complete.

## Documentation and Handover
- [ ] User-facing documentation is updated.
- [ ] Technical documentation is updated.
- [ ] Release notes/change log entry is added.
- [ ] Support/operations handoff is complete.

## Dependencies and Release Readiness
- [ ] All dependencies are resolved or accepted by owner.
- [ ] Rollback/mitigation plan is documented.
- [ ] Stakeholder review is complete.
- [ ] Final sign-off captured.

## Sign-Off
- Product Owner: [Name / Date]
- Engineering Lead: [Name / Date]
- QA Lead: [Name / Date]
- Security/Compliance (if required): [Name / Date]
